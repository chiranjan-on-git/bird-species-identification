# Bird Species Identification

## Project Overview

A research-oriented bird species identification
system using pretrained vision-language models
and lightweight image classification architectures.

## Hardware

- Apple M1
- 8GB Unified Memory
- Apple Metal Performance Shaders (MPS)

## Technology Stack

- Python 3.11
- PyTorch
- Torchvision
- OpenCLIP
- Scikit-learn
- Streamlit

## Research Objectives

1. Develop a bird species classification system.
2. Compare vision-only and vision-language approaches.
3. Evaluate classification accuracy and latency.
4. Generate explanations based on visual attributes.
5. Build a reproducible experimental pipeline.

## Dataset

CUB-200-2011
